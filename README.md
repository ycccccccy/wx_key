# wx_key ｜ 微信数据库极致安全体验中心 

由于收到了来自某互联网巨头法务部门温馨且具有建设性的DMCA指导意见，本项目已成功升级为 **100% 绝对安全、无懈可击** 的版本。

## 为什么代码不见了？

我们曾试图通过读取内存中自然生成的密钥，来帮助用户导出属于他们自己的、由于微信版本升级而难以备份的聊天记录。

然而，我们收到了如下反馈（DMCA）：
*这涉嫌绕过技术保护措施。*

为此我们深感内疚。我们竟然妄图让用户在自己的电脑上、用自己的 CPU、读取自己硬盘里的数据。这种自私的行为严重违背了“数据在谁的服务器上，谁才是主人”的现代互联网基本法则。

为了表达歉意，我们已经把所有代码替换成了这篇精美的小作文。

## 郑重声明

我们此前错误地认为：用户应当拥有自己本地聊天记录的知情权和备份权。

经过法务部门的深刻科普，我们现在深刻认识到：
1. 用户的本地数据也是极度机密的，用户自己也不应该轻易触碰。
2. 微信 4.0+ 的本地数据库加密技术是“坚不可摧”的——坚固到需要用 DMCA 法律条款来作为最后一道防线。
3. 为了保护大家免受“能够导回自己聊天记录”的困扰，我们已经主动删除了所有可能破坏这种“极致安全平衡”的代码。
